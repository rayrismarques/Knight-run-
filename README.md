# Knight Run!⚔️

&#x20;

A 2D pixel-art endless runner. Control a knight, jump over obstacles, and survive for as long as you can.







## How to play

There is only one control:

|Key|Action|
|-|-|
|**SPACE**|Start the game (from the main menu or after a game over) and make the knight **jump**|



## Download and run

1. Extract the zip. Keep `main.exe` and the `asset` folder together.
2. Double-click `main.exe`.

**Requirements:** Windows 64-bit. No installation needed.



### Antivirus / SmartScreen warning

The game is packaged as an unsigned ".exe", so Windows SmartScreen or your antivirus may flag it as unrecognized.
